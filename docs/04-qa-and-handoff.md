# 검증 및 인수인계

## 자동 검증

원본 dist/와 tests/를 바이트 그대로 복사했습니다. 원본 커밋은 VERSION.json에 기록했습니다. 패키지 생성 후 테스트 실행, ZIP 무결성 검사, 압축 해제본에서 동일 테스트 재실행을 수행합니다. 결과는 test-results.txt와 DELIVERY-VERIFICATION.txt를 확인하세요.

| 테스트 | 주요 범위 |
|---|---|
| game.test.cjs | 자동차/시민 반사, 손실, 콤보, 멀티볼 등 게임 회귀 |
| audio.test.cjs | 오디오 생성·재개·복구 경로 |
| app.test.cjs | 설치·전체화면·화면 맞춤 관련 회귀 |
| enemy-animation.test.cjs | 시각 애니메이션, 판정/점수 분리 |
| bazooka.test.cjs | 지원 스킬, 위기 조건, 로켓·피해 |
| progression.test.cjs | 실제 방어선, 패배 원인, 최후 저항, 난이도, 50 완주·무한 모드 |

이 테스트는 Node의 VM 및 Canvas/DOM/오디오 모형을 사용합니다. 실제 휴대폰에서의 렌더링 품질, 음량/음질, PWA 설치 성공, 장기 플레이 체감을 보증하는 기기 테스트는 아닙니다. 이번 패키징에서 게임 소스를 변경하지 않았습니다.

## 다음 배포 전 수동 확인

1. iOS Safari, Android Chrome, 데스크톱에서 시작·드래그·키보드·일시정지와 화면 회전을 확인합니다.
2. 최초 사용자 입력 후 소리, 음소거, BGM만 끄기, 백그라운드 복귀 후 소리를 확인합니다.
3. 자동차 본체 반사 → 시민 반사/퇴장 → 시민 없는 위치의 공 손실을 각각 재현합니다.
4. 더블+트리플 6공 상태와 각각의 만료, 남은 공이 있을 때 하트가 줄지 않는지 확인합니다.
5. 시민 복귀 콤보, 바주카 긴급 지원 및 45초 제한, 폭발 범위와 마지막 적 처치 시 클리어를 확인합니다.
6. 20 이후 첫 위기 구제와 두 번째 위기 패배, 방어선/마지막 하트의 서로 다른 원인 표시를 확인합니다.
7. 50 완주, 새로고침 후 해금 유지, 무한 모드 진입, 일반 모드 재시작을 확인합니다.
8. 기존 설치앱 업데이트와 새 설치, 오프라인 재접속을 HTTPS 환경에서 확인합니다.

## 인수인계 완료 기준

수신자는 ZIP을 풀어 README의 명령으로 게임을 실행하고 테스트 6개가 통과하는지 확인합니다. 새로운 Git 저장소를 만들고 자신의 배포 환경에 dist만 업로드하면 개발을 계속할 수 있습니다. 원본 공개 사이트는 이 패키지를 전달해도 자동으로 바뀌지 않습니다. 현재 서버 계정이나 개인 최고점/해금 데이터는 ZIP에 담지 않습니다.
