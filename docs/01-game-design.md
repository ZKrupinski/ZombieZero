# 현재 구현 기준 게임 기획서

## 게임 개요와 방향

오픈카 위의 주인공이 테니스 라켓으로 공을 반사하여 내려오는 좀비 군단을 물리치는 세로형 아케이드 게임입니다. 코믹한 굵은 도트 스타일, 8bit 멜로디에 베이스와 드럼을 더한 음악, 시민 응원과 최후 방어가 특징입니다. 기존 캐릭터와 아트 스타일을 유지하며 개선하는 것이 개발 원칙입니다.

캠페인은 50스테이지, 완주 후 끝없이 이어지는 무한 모드를 해금합니다. 초반 접근성을 높이고 후반 속도 증가를 완화한 현재 버전입니다. 실제 일반 플레이어의 50스테이지 도달률을 측정한 것은 아닙니다.

## 기본 규칙 및 화면

- 게임 월드 논리 해상도는 **450×710 고정**입니다. 모바일 전체화면에서도 종횡비가 달라도 물리·좀비와 주인공 간 거리·방어선 좌표를 바꾸지 않습니다. 가로/세로 화면 중 짧은 축에 맞춰 동일 비율로 게임판을 확대·축소하고 남는 공간은 고정 배경으로 처리합니다. 입력·전투·스프라이트는 450×710 내부 좌표를 사용합니다. 실제 캔버스 픽셀 해상도는 화면과 DPR에 맞춥니다.
- 처치 콤보는 상단 중앙의 **작은 반투명 큐브 배지(183×57 논리 픽셀)**로 표시합니다. 기존 310×100에서 약 42% 축소했고, 스테이지 숫자와 분리했습니다. 6단계별 색상·문구·파편은 유지하되, 처치 후 약 1.45초만 등장해 빠르게 사라지므로 좀비 시야를 가리지 않습니다. 실제 콤보 지속시간 6초와 시민 복귀 규칙은 그대로입니다. 보스 체력 게이지와 수치 UI는 표시하지 않으므로 콤보와 겹치지 않습니다.
- 모바일에서 게임 시작·무한 모드 버튼을 터치하면 브라우저가 허용하는 경우 같은 사용자 입력으로 네이티브 전체화면을 요청합니다. iOS Safari 등 Fullscreen API 미지원 환경은 전체화면을 강제로 열 수 없으므로 화면 가득 채우는 웹 레이아웃 또는 홈 화면 설치 앱 모드로 대체합니다.
- HUD는 450×710 고정 게임판에 맞춰 **좌상단 점수 / 상단 중앙 스테이지 / 우상단 작은 일시정지·설정 버튼**으로 타이트하게 정렬합니다. 콤보는 HUD 숫자에 섞이지 않는 상단 중앙 Y≈52의 **소형 반투명 큐브형 오버레이**입니다. 전체 게임판은 화면 비율과 관계없이 일률적으로 확대·축소하며 남는 화면은 배경으로 채웁니다. 노치·안전영역과 하단 홈 인디케이터를 고려합니다.
- 모바일은 화면의 조작 가능한 영역 어디에서나 좌우 드래그. UI 버튼과 대화상자는 입력에서 제외합니다. 데스크톱은 마우스, 방향키/A·D, Space 서브, Esc 일시정지를 지원합니다.
- 라켓을 지나친 공도 자동차 본체에 닿으면 위로 반사합니다. 시민 또는 보호막도 마지막 방어 역할을 합니다.
- 여러 공 중 하나가 빠져도 나머지 공이 있으면 계속 플레이합니다. 모든 공을 잃었을 때 하트가 감소합니다. 더블/트리플볼 시간 종료로 줄어드는 추가 공은 각각 현재 위치에서 청록색 잔광·링·큐브 파편으로 0.5초 동안 소멸하며, 화면 아래로 빠진 공은 분홍색 0.65초 소멸 이펙트로 구별합니다. 스테이지 클리어에 남은 공은 금빛으로 정리합니다.
- 마지막 적이 제거되면 남은 아이템을 기다리지 않고 즉시 클리어 연출로 전환합니다. 클리어 보너스 500점.
- **일반 좀비와 보스 모두 체력 게이지 및 체력 수치 UI를 표시하지 않습니다.** 보스의 실제 HP·피해 계산과 패턴은 기존대로 유지합니다. 결과창에는 진행 스테이지, 클리어 수, 점수와 최고점이 표시됩니다.
- 공 반사선은 기본 450×710 화면에서 Y=584(기존 Y=604 대비 20px 위)입니다. 세 캐릭터의 차·무기 아틀라스는 192×192 원본 PNG 셀을 유지하면서 인게임 108×108px(기존 154px의 약 70%)로 렌더링하고, 화면상 손·무기 높이에 맞춰 실제 공 반사 판정도 올립니다. 차량 본체의 기존 최후 방어 판정과 캐릭터별 반사 폭은 유지합니다.
- 실제 방어선 Y=565에 적이 도달하면 하트가 남아 있어도 패배합니다. 공 손실 패배와 구별되는 1.8초 원인 연출 후 결과창을 표시합니다.

## 시민 아트·애니메이션 v41

- 기존 18명의 시민 방어·복귀·응원 규칙과 충돌 판정은 유지하고, 도트형 임시 캐릭터 이미지를 **8종의 서로 다른 컬러풀한 큐브형 시민**으로 교체합니다. 18명의 시민은 8종의 외형을 순서대로 재사용하여 총 배치 수를 유지합니다.
- 시민 종류: 노란 안전모 작업자, 분홍 머리 소녀, 흰머리 안경 할아버지, 청록색 모자·헤드폰 소년, 보라 옷의 머리묶은 여성, 넥타이를 맨 회사원, 꽃 모자를 쓴 할머니, 빨간 모자의 스포츠 소년입니다.
- 각 시민은 **투명 PNG 2종, 4프레임씩 총 8프레임**으로 응원·반격(희생) 두 동작을 가집니다. 게임용 아틀라스는 각각 1024×512px(8열×4행, 셀 128px), 렌더 크기는 35×46px입니다. 발 기준 정렬과 작은 알파 잔여물 제거를 적용했습니다.
- 응원 중에는 팔 들기·환호 애니메이션이 반복되며, 임시 투척/바주카 지원 시 공격 애니메이션으로 전환합니다. 공을 대신 막아 희생하는 시민은 0.8초 동안 반격→충격→탈진을 순서대로 보여 주고 퇴장하며, 5킬마다 돌아오는 시민은 기존 복귀 연출을 유지합니다.
- 스프라이트 로딩 실패나 구형 브라우저에서도 게임은 중단되지 않도록 기존 사각형 시민을 폴백으로 사용합니다. 기존 시민의 수, 구출·희생시 공 반사, 공격 데미지 및 기획상 쿨타임은 변경하지 않았습니다.

## 좀비 및 보스

기본 좀비 체력은 1~2스테이지에 2, 3~19스테이지에 3부터 시작하며 후반에 증가합니다. 1스테이지는 9열×2행(18마리)으로 시작하고 2스테이지부터 대열이 커집니다. 체력 등급은 그린 1, 블루 2, 골드 3, 퍼플 4, 레드 5입니다. 단계별 무작위 배치이며 외형과 체력 등급은 별개입니다. 7열, 최대 5행. 보스 스테이지는 첫 두 행 가운데 3열을 비웁니다.

| 외형 | 등장 시작 스테이지 |
|---|---:|
| 워커 | 1 |
| 스크리머 | 2 |
| 펑크 | 4 |
| 봉합체 | 5 |
| 늑대 감염체 | 7 |
| 실험체 | 8 |
| 방호복 | 10 |
| 메카 감염체 | 12 |

3스테이지마다 보스가 등장합니다. 봉합 거인 → 울프 킹 → 브레인 메카 → 아머드 스크리머 순환. 일반 판정 33×44, 보스 66×88. 보스 체력은 `round(24 + min(wave,10)*4 + max(0,wave-10)*1.2)`입니다.

일반 좀비는 빽빽한 대열에서도 개별적으로 좌우 ±6px 범위에서 0.38~0.66초간 짧은 실제 대각선 스텝을 밟으며, 0.27~0.65초간 정면 하강을 섞습니다. 시작 타이밍·방향은 좀비별로 분산되고, 실제 X 이동 방향과 좌/우대각 8프레임 스프라이트가 일치합니다. 피격·밀침·큰 대각 돌파 중에는 짧은 스텝이 중단되며, 이동 전후 적끼리 겹치는지를 검사합니다. 빈 열로 빠르게 뛰어드는 기존 돌파 패턴은 별도로 유지합니다.

6종의 움직임 성격, 비대칭 팔/눈꺼풀, 턱, 머리, 어깨 움직임은 시각 연출입니다. 피격 시 최대 50px 물리 넉백과 인접 좀비 최대 8개체 연쇄 밀침이 발생합니다. **공이 위에서 아래로 내려오며 뒤통수에 명중하더라도 좀비가 아래(Y+)로 밀리지 않습니다.** 순수 하향 충격은 피격·피해·이펙트만 발생하며, 아래 대각선 충격은 수평 성분으로만 밀립니다. 위쪽·좌우 넉백 강도 및 연쇄 밀침은 기존 그대로 유지합니다. 이는 일반 좀비의 점진적 하강 및 특수 대각 이동에는 영향을 주지 않습니다. 충돌 좌표는 안전한 목적지로 확정하되, 화면의 좀비는 약 0.20초 동안 감속 이동하고 잔상은 총 0.32초 유지하여 워프를 방지합니다. 사망 즉시 적 목록에서 제거하고 점수를 한 번만 지급한 뒤 독립된 파편을 그립니다.

## 난이도 곡선과 구조

```text
stage = min(50, wave)
n = min(9, max(0, stage-1))
late = max(0, stage-10)
기본 진군 속도 = 2.7 + 0.22*n + 0.006*n² + 0.07*late + 0.0008*late²
무한 모드 추가 속도 = min(9, max(0, wave-50)*0.035)
```

색상별 속도 배율은 1.10/1.04/0.97/0.89/0.82, 보스는 0.62입니다. 슬로우 중에는 추가로 0.4배. 앞의 적과 간격을 유지하여 겹침을 방지합니다. 매 5스테이지 클리어 후 다음 단계로 넘어갈 때 하트 1개를 캐릭터 최대치까지 회복합니다.

20스테이지부터 한 판에 한 번, 첫 방어선 돌파 또는 마지막 하트 손실 직전에 최후의 저항이 자동 발동합니다. 적들을 목표 180만큼 뒤로 밀되 상단과 다른 적과의 간격을 보존합니다. 피해는 주지 않습니다. 마지막 하트 손실로 발동한 경우 하트 1, 서브 대기 공, 보호막 4초를 제공합니다.

50스테이지 클리어 후 무한 모드가 해금됩니다. 내부 wave=51부터 UI에는 ∞1로 표시하며 계속 진행합니다. 최고점과 해금 상태는 해당 브라우저 localStorage에만 저장됩니다. 장치 간 동기화나 계정 시스템은 없습니다.

## 캐릭터 프레임 정렬·생명 및 점수 HUD v40

- 3인 자동차 공격 스프라이트는 **기존 3×8개, 192×192 투명 프레임**, 플레이 표시 크기 108×108(원래의 70%)를 유지합니다. 차량 바닥을 에이스 기준 동일 프레임 높이(약 y=179)에 맞추기 위해 루비(금발)의 8프레임을 11px, 리암(빨간 머리)의 8프레임을 7px 내려 정렬했습니다. 빨간 머리의 상단은 원본 머리 표면 색상으로 복원해 프레임 맨 위가 잘리지 않도록 약간의 투명 여백을 확보했습니다. 소스·아틀라스와 캐릭터 선택화면 모두 같은 파일을 사용합니다.
- 플레이 HUD **왼쪽 상단**은 이전 총점수 대신 **큰 빨간 큐브 하트 이미지와 남은 하트 숫자(×3 / ×2 / ×1)**로 표시합니다. 히트/생명감소 및 주인공(2~3 목숨) 선택에 따라 실시간 갱신됩니다. 기존 하단 하트 문자 줄은 숨깁니다.
- **상단 중앙**에는 스테이지와 누적 점수를 나란히 배치하고, 우측 일시정지·설정 버튼은 그대로 유지합니다. 모든 위치·크기는 450×710 기준 해상도를 사용해 모바일과 폴더블에서 함께 비례 조정됩니다.
- 이 변경은 아트와 HUD의 배치만 변경하며 공 반사선(Y=584), 기존 좀비 하강, 아이템, 무기 공격, 하트 소진 및 점수 계산 판정에는 영향이 없습니다.

## 스킬 표시 UI v37

- 하단의 긴 지속시간 카드, 아이템 설명 문구 및 `초` 숫자 표시는 제거했습니다. 활성 아이템은 자동차 하단에 **17×17 논리 픽셀** 크기의 복셀 비트맵 아이콘만 따라붙고, 바깥쪽 약 1.4px의 얇은 **남은 시간 원형 게이지**만 남습니다. 아이템이 여러 개 동시에 활성화되어도 한 줄로 정렬되고, 자동차가 좌우 끝에 있어도 화면 밖으로 벗어나지 않습니다.
- 관통샷은 승인된 **황금 탄환이 큐브를 관통하는 투명 PNG**를 적용했습니다. 나머지 7개 아이템도 동일한 128px 원본을 기반으로 한 큐브 아트 비트맵입니다. 실제 획득 가능한 드롭에도 해당 그림 아이콘을 사용합니다.
- **위에서 내려오는 미획득 아이템 아이콘만** 게임 기준 34×34→**46×46px**로 확대했습니다(약 35% 상승). 약한 ADD 블렌드 16%와 이미지 외곽 8~11px 소프트 글로우를 적용하되, 투명 PNG 자체는 그대로 유지합니다. 아이템 위의 십자형 벡터 장식(가로·세로 사각형)은 완전히 제거했습니다. 획득 시 실제 충돌 위치에서 아이콘이 잠깐 확대·상승하는 0.62초 이펙트, 원형 플래시와 작은 큐브 파편으로 확인감을 부여합니다. **자동차 아래 활성 효과 아이콘은 17×17px 그대로 유지**합니다.
- 게임 플레이 중 아이템 획득 때는 설명 문장이나 아이템 이름을 이펙트 텍스트로 표시하지 않으며, 짧은 빛과 사운드, 활성 아이콘만으로 피드백합니다.
- 스테이지/콤보/점수의 기본 위치, 실제 아이템 지속시간, 반사 판정, 공과 좀비 이동은 바꾸지 않습니다.

루비는 지속 시간을 1.25배 적용합니다. **관통샷은 파워볼과 중첩 시 기존 파워볼 2배에 관통 크리티컬 2배를 곱하며**, 더블/트리플볼의 모든 공에도 동일하게 적용됩니다. 관통샷 종료 즉시 원래의 적 타격 반사로 돌아옵니다. 같은 스킬 재획득은 시간 갱신이며 더블/트리플 타이머는 독립적입니다. 스킬 종료 시 허용 공 수를 정리하며 이미 잃은 공을 자동으로 계속 복제하지 않습니다. 스테이지 전환과 공 전체 손실 시 기존 스킬을 정리합니다.

체력 2 이상 일반 적 처치 시 45% 확률로 아이템, 보스는 보장 드롭. 체력 1 일반 적은 드롭하지 않습니다. 아이템이 생겼을 때 바주카 선택 확률은 안전 0.5%, 경계 10%, 위기 28%입니다. 이는 적 한 마리당 직접 드롭 확률이 아닙니다.

바주카는 1~2스테이지에는 자동 등장하지 않으며 이후 한 스테이지에 1회만 지원합니다. 생존 시민이 있어야 하며, 이전 지원 생성/획득 후 45초 이상, 활성 바주카·대기 바주카 아이템·비행 로켓이 없는 조건을 적용합니다. 위기 상태가 3초 유지되면 별도 긴급 지원 아이템을 자동차 X/Y485에 생성합니다. 대기 서브 중에는 발동하지 않습니다.

위기: 적 하단≥475, 또는 하단≥380이면서 하트 1/시민 5명 이하. 경계: 적 하단≥390, 또는 하트 1/시민 8명 이하. 나머지는 안전입니다.

## 크리티컬과 관통샷 연출

- 기본 크리티컬(체력 3 이상인 풀 체력 일반 적의 확률 즉사)은 그린 11%→**15%**, 특수형 6.5%→**9%**로 소폭 상향했습니다. 보스와 화염 지속 피해는 기존 확률 즉사 대상에서 제외됩니다.
- 크리티컬은 밝은 옐로 골드 플래시·픽셀 파편·테두리가 있는 **CRITICAL!** 이미지형 텍스트를 약 0.72초 표시합니다. 관통샷 명중은 **PIERCE CRIT!**으로 구별하며, 보스 포함 모두 2배 피해를 주지만 즉사하지 않습니다.
- 관통 중 같은 적의 타격 박스에 걸쳐 있을 때 반복 피해가 발생하지 않도록 개별 공마다 접촉 목록을 보관하고, 박스를 벗어나야 같은 적에 재타격합니다.

## 시민과 콤보

18명의 시민이 화면 하단을 채웁니다. 시민은 한 번 공을 반사하고 사라집니다. 보호막/자동차/시민 반사와 공 손실의 중복 처리를 막아야 합니다. 시민은 3.5~5.5초 간격의 잡동사니 투척으로 0.25 피해를 줄 수 있습니다.

처치 후 6초 안에 다시 처치하면 처치 콤보가 이어집니다. 2~4 NICE(라임), 5~9 COOL(시안), 10~14 GREAT(골드), 15~19 AWESOME(핑크), 20~29 UNSTOPPABLE(보라), 30 이상 LEGENDARY(골드·보라)로 표현합니다. 콤보 5회마다 사라진 지 8초 이상인 시민 중 한 명을 복귀시킵니다. 복귀한 시민은 다시 한 번 방어할 수 있습니다.

처치 콤보는 상단 중앙의 작은 반투명 큐브 배지로 표시하고, 처치마다 짧게 팝업·픽셀 파편 효과가 발생합니다. 1.45초 뒤 시야 확보를 위해 숨기며, 실제 콤보 판정은 6초 지속합니다. 스테이지 숫자와 분리되어 있으며 배지가 보이는 동안만 보스 체력바는 소폭 아래로 이동합니다. 시민 머리 위 말풍선은 일반 응원과 퇴장/복귀/바주카 이벤트를 구별합니다.

점수 계산에 사용하는 타격 콤보 `combo`와 화면의 처치 콤보 `killCombo`는 다릅니다. 생존 적 타격은 25점, 처치는 일반 `100*최대체력`, 보스 1500에 `min(combo,10)*10`을 더합니다. 타격 콤보는 라켓 반사 시 초기화되므로 두 콤보를 합치지 마세요.
