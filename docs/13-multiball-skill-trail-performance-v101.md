# v101 멀티볼 관통·화염 스킬 트레일 성능 패치 (2026-11-17)

- 실제 병목 확인: 기본 공 트레일 1개 + 별도 Bloom/헤일로 2번 + 스킬 리본 + 화염 3중 리본/좌우 불꽃 + 관통 번개 3-pass Blur/여러 갈래 + 반사광 20×2를 **공마다** 중첩.
- 3개 이상 공과 화염/관통이 동시에 활성화되면 **스킬 자체의 연속 그라디언트 코어가 기본 트레일과 중복되어**, 기본 리본/2중 halo를 제거한다. 일반 공 1~2개 및 FX-off 상태는 기존 렌더 경로 그대로 유지.
- 화염 스킬 트레일 3중 폴리곤/다수 tongue → 1개 연속 선형 웨이크 + 드문 불꽃. **원래 트레일 길이 유지.**
- 관통 스킬의 3겹 블러 볼트/갈래 → 1개 연속 번개 필라멘트, 속칭 전기 fork는 51px 간격으로만; 공 주위 번개도 2개씩(원래 앞3/뒤4).
- 스킬/화염 꼬리 입자 밀도 5~6px → 13~14px에 연속 코어를 유지하므로 점선으로 끊기지 않음.
- 바닥 반사광은 최대 20×2 풀 → 최대 10×1 밝은 풀. 약한 반사광과 원래 스트로크 중심은 유지.
- **60FPS 보장 주장 금지:** CI가 검증하는 것은 함수 호출 수·알파 누적 및 기존 조작/물리 경로 불변이다. 실기기 성능/품질은 검증이 별도로 필요하다.
- **기능 불변:** 공 속도/충돌/스킬 지속시간/딜/데스/보스/카메라/이미지·FX shader 설정 없음.
