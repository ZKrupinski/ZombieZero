# ZOMBIE ZERO — 전체 좀비 사망 / 크리티컬 사망 제작 로드맵

작성: 2026-11-16 · 기준: v95 (e13e6ecd50fc612cd4b9f47305e7df9ee2964529)
상태: 제작 계획 / 백로그. 이 문서를 커밋하는 것과 실제 PNG 적용은 별도 단계.

## 목표

- v95 그린 좀비의 **정면 우세 / 약간 높은 시점**, 살아 있는 모습과 자연스럽게 연결되는 첫 프레임, 큐브·박스가 해체되듯 넓게 날아가는 후반부를 **모든 좀비와 보스**에 확장.
- 일반 사망과 크리티컬 사망은 별도 아트. 크리티컬은 뇌·뚜껑·케이스·중심 장치 등 종별 핵심 요소를 더 강조하고 확산 폭과 타격 강도를 확실히 높임. 지나치게 잔혹한 표현 없이 원작의 귀엽고 입체적인 저폴리 조형 유지.
- **알파 PNG만** 사용. 흰색 외곽 테두리/검은 배경/불필요한 바닥 그림자/알파 구멍/파편 간 프레임 침범 금지. 파편이 끝으로 갈수록 축소되어 보이지 않도록 전개 면적 확대.
- 사망 연출은 콜라이더, 물리, 피해량, 스킬, 점수, 아이템 드롭, 스테이지 클리어와 분리. 기존 런타임 조건을 임의 변경하지 않음.

## 색상/리소스 공유 판정

1. **현재 검증 완료된 팔레트 재사용:** 그린 좀비 5색(클래식 그린, 모스, 씨글라스 민트, 스모키 블루, 더스티 라벤더). ZZGreenPalette.paletteFor(z)로 걷기/피격/일반 사망/크리티컬 사망의 피부 부분만 동일하게 재색상화하고 최초 로딩 시 캔버스로 캐시. 눈·입·빨간 옷·분홍 뇌·알파는 변색하지 않음.
2. **포즈/파괴 콘티만 공유 가능:** 레드/블랙 드럼통, 옐로/레드/블랙 브레인 큐브. 이 5종은 현재 **서로 다른 PNG 아틀라스와 외형/알파 영역**을 가진다. 동일 지오메트리의 색 차이만으로 확인되지 않았으므로 **한 장의 시트를 색만 바꿔 쓰는 구현은 승인 전 금지**. 개별 색/디자인/파편 형태를 유지한 아트 제작 후, 공용 모션 데이터 사용은 가능.
3. **고유 원화·소재 필수:** 포장 박스, 나무 상자, 빅 좀비, 쓰레기통 보스. 서로 다른 실루엣 및 파편 물성을 갖는다.
4. 캐릭터 아이덴티티 컬러를 체력/등급 컬러로 덮어쓰지 않는다.
5. 이전 대화에서 예시로 언급된 **레드후드 엘리트** 등은 현재 ZOMBIE ZERO runtime normal/bosses 목록에 **존재하지 않는다**. Project Z의 적과 혼동하여 새 슬롯을 만들지 않는다.

## 제작 가이드 / 프레임 스펙

- **일반 적:** 각 일반 사망 8프레임, 크리티컬 8프레임 **제안**. 최종 포맷은 기준작 v95의 8×96×128, 768×128 실행 텍스처를 벤치마크하되, 개체 폭·파편에 맞춰 **셀을 더 크게 잡을 수 있다**.
- **보스:** 각 일반/크리티컬 10~12프레임 **제안 (아직 승인/구현되지 않음)**. 기존 빅/쓰레기통 보스 걷기·피격의 256×256 셀 HD 이미지를 출발점으로 사용. 보스 파편이 끊기지 않는 충분한 소스 셀 및 화면상 확산 범위 확보.
- 정면 우세 + 약간 높은 카메라, 정사각 헤드와 몸통의 입체 두께 유지. 최초 프레임은 살아 있는 형태와 **동일 색/비율/발 피벗**. 첫 피격 이후 짧은 흔들림 → 갈라짐/코어 노출 → 강하게 사방 확산 → 큰 파편이 천천히 흩어짐.
- 프레임 당 모든 비투명 픽셀을 **해당 셀 내부**에 유지. 커팅 전후 흰 알파 프린지, 잔여 배경, 프레임 혼입·구멍·잘림 검증. 상단/좌우/하단 안전 여백을 프레임별 파편 최대 범위 기준으로 산정.
- 일반 사망은 분해 자체가 읽히게, 크리티컬은 캐릭터 고유 포인트를 크게 강조하고 **일반보다 파편 이동 범위 및 발광 강도를 높임**. 다만 Bloom/ADD는 기존 FX 레이어와의 중복 과다 노출 방지.
- 실행용 다운샘플 비트맵과 고해상도 원본은 별도 보관; 실제 게임 화면에서 가독성/알파 테스트 통과한 PNG만 dist에 배치.

## 현재 코드 연동 / 건드리지 말아야 할 것

- 그린: dist/assets/ip/green-death-loader.js에서 green-death-normal-v95.png 및 green-death-critical-v95.png(8×96×128). 오류 시 기존 480×96 구 사망 아틀라스로 폴백. 5색은 동일 ZZGreenPalette 사용.
- 그 외 9종: dist/assets/ip/v2/object-zombies.js. 현재 1024×512 (128×128×30프레임), 보스 HD는 2048×1024 (256×256×30프레임). 걷기 0~23, 피격 24~25, **일반 사망 26~27, 크리티컬 28~29**, 현재는 두 개의 그림을 시간에 따라 블렌딩해 보여준다. 나머지 9종의 새로운 다프레임 시트는 **아직 미적용**.
- dist/game.js의 damage → enemyDeath → updateEnemyVisuals / drawEnemyDeaths 경로 사용. 현재 사망 표시시간: 일반 적 보통 0.52초/크리티컬 0.58초, 보스 보통 0.78초/크리티컬 0.94초(기존 hit freeze 추가). 타임라인 변경 시 별도 시연·승인.
- 크리티컬 분기에는 damage(criticalHit, piercingCritical)가 관여. **보스는 풀HP 즉사 크리티컬 대상이 아니며**, piercingCritical 여부에 따라 크리티컬 시퀀스 진입 가능. 새 사망 아트 때문에 즉사/HP/크리티컬 발동률을 바꾸지 말 것.
- 빨간 드럼통은 죽을 때 explodeRedBarrel(z)가 기존 화염 기믹으로 작동. 애니메이션 재생이 이를 중복 호출해서는 안 된다.
- 처치 즉시 콜라이더 제거, 점수·드롭·적 카운트·스테이지 진행. 사망은 보이는 잔상일 뿐. 새 이미지 미로딩 시 기존 2키프레임/Canvas 폴백. 보스 HD 실패 시 기존 128px 원본 유지.
- FX 트레일, ADD/Bloom, 타격감, 멀티볼 최적화에는 불필요한 변경 금지.

- 기존 게임 `yellow_brain_cube.png`와 `red_brain_cube.png`를 눈으로 대조했다. **두 종 모두 검은 머리카락/검은 그린 좀비 뚜껑이 없다.** 상단 분홍 뇌가 노출된 고유 노랑/빨강 케이스다.
