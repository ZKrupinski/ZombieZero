1. 원본의 α≥74 연결 실루엣을 보존하고 원본의 먼지·잔상을 제거한다.
2. 테두리 반투명 픽셀은 α=65~229를 0~255로 정리하고 불투명한 인접 RGB로 엣지 컬러를 채운다. 흰색 배경색으로 채우지 않는다.
3. 192px 프레임에 머리·가방·바퀴를 통째로 넣는다. **차량 바퀴 접지 높이를 매 프레임 동일 기준**으로 사용한다. 첫 Idle 프레임은 원본 전체 구성 그대로이다.
