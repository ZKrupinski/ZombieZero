# ZOMBIE ZERO · 좀비 제로

Zombie Balls 배포 버전 19의 독립 개발 사본입니다. 기존 게임 코드, 기획, 그래픽 생성 코드, 사운드 합성 코드, 테스트와 확보한 로고 원본을 보존했습니다.

## 실행
```sh
python3 -m http.server 8000 --directory dist
```
http://localhost:8000 에서 실행합니다.

## 검증
```sh
node tools/test.cjs
```

## 자료
- `dist/`: 게임 소스와 실행 리소스. 새 이름, 공유 주소, PWA 식별자/캐시 적용.
- `docs/`: 기존 구현의 기획·개발·리소스 문서.
- `assets-source/`: 기존 고해상도 BI.
- `archive/`: 원본 인계 ZIP, 원본 버전 정보, 로고 3종. 원본 파일은 수정하지 않음.

## 원작 아트 P1~P2 검토 브랜치 (2026-11-13)
`main` 공개 배포본을 유지한 채 `art/original-ip-foundation-20261113`에서 원작 아트 리뉴얼을 진행합니다. 2026 브랜딩 PDF의 공식 **사물 좀비 10종 + 생존자 3인**을 256×256 투명 PNG 아틀라스로 게임에 적용했습니다. 일반 적 8종, 2종의 보스(4가지 주기로 재등장), 주인공 3종이 원작 13종은 현재 **도움말의 캐릭터 컬렉션/레퍼런스에만** 사용됩니다. 기존 아케이드의 실제 적/생존자 플레이 화면은 **정면 위주 약한 반측면 탑뷰**에 적합한 새 스프라이트가 제작되기 전까지 기존 Canvas 렌더러를 사용합니다. 아이소메트릭 원화 기반의 사망 파편 적용은 취소하고 기존 Canvas 파편을 유지합니다. 캐릭터 발밑 그림자와 차량 하단의 임시 그림자도 제거했습니다. 이미지를 불러오지 못하면 기존 Canvas 렌더링으로 복귀하며, 조작·충돌·단계 진행 로직은 그대로 보존합니다.
 
원본 PNG 분할 파일과 그린 좀비 **이동 8프레임/피격 4프레임/사망 6프레임** 리깅 모션 시안은 대화의 별도 QA ZIP으로 제공됩니다. 그 시안은 **원본 정지이미지의 부분 워프**이며 손발을 독립 작화한 최종 스프라이트가 아닙니다. 게임 내에는 기존 bob/lean/hit/death 실시간 모션이 적용되고, 별도의 8프레임 애니메이션 시트 재생은 아직 연결하지 않았습니다. 게임용 정면·약한 반측면 탑뷰 캐릭터 및 원작 로고·배경은 다음 리뉴얼 대상입니다. 카메라/아트 분리 규칙은 `docs/09-camera-and-shadow-free-sprite-contract.md`를 참고하세요. 브랜치 테스트는 자동 회귀 테스트를 통과했지만 실제 모바일 그래픽 QA·공개 배포는 **미완료**입니다.
