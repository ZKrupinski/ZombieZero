# ZOMBIE ZERO · 좀비 제로

Zombie Balls 배포 버전 19의 독립 개발 사본입니다. 기존 게임 코드, 기획, 그래픽 생성 코드, 사운드 합성 코드, 테스트와 확보한 로고 원본을 보존했습니다.

## 실행
```sh
python3 -m http.server 8000 --directory dist
```
http://localhost:8000 에서 실행합니다.

## 검증
```sh
node tools/test.cjs
```

## 자료
- `dist/`: 게임 소스와 실행 리소스. 새 이름, 공유 주소, PWA 식별자/캐시 적용.
- `docs/`: 기존 구현의 기획·개발·리소스 문서.
- `assets-source/`: 기존 고해상도 BI.
- `archive/`: 원본 인계 ZIP, 원본 버전 정보, 로고 3종. 원본 파일은 수정하지 않음.

## 원작 아트 P1 검토 브랜치 (2026-11-13)
현재 `main` 배포본을 변경하지 않고 `art/original-ip-foundation-20261113` 브랜치에서 정식 그린 좀비 원본의 투명 PNG 파생본(96×128)을 워커 렌더러에 연결했습니다. 실제 원본 아트 리뉴얼은 검토용 PR에서 진행 중이며, 기존 캐릭터와 게임 로직은 유지됩니다. 코드·이미지 로드 실패 시 기존 Canvas 렌더링으로 복귀합니다. 브랜드 PDF(`ZOMBIE_ZERO_Brand 2026.pdf`)의 공식 사물 좀비 10종, 생존자 3인, 세계관/협업 로드맵을 `docs/08-brand-2026-alignment.md`에 정리했습니다. **전체 원작 캐릭터 교체와 공개 배포는 아직 완료되지 않았습니다.**

## 아트 리뉴얼 상태
현재는 독립 복사 기반 버전입니다. 새 타이틀은 임시 텍스트이며 기존 게임 아트는 보존되어 있습니다. 원작의 정확한 캐릭터·배경·UI 참고 자료 확인 후 비트맵 아트워크로 교체할 예정입니다. 과거 대화의 모든 첨부 이미지 또는 원작 프로젝트 파일 전체를 확보한 것은 아닙니다.
